## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/TayyabHanif11/DIP-Lab-2024-SE-11.git
```

**2. Navigate to a lab folder**

```bash
cd DIP-Lab-2024-SE-11/Lab01
```

**3. Install dependencies (where applicable)**

```bash
python -m pip install -r requirements.txt
```

**4. Run a Python program**

```bash
python basics.py
```

Refer to individual lab files for their specific implementations.
