**DIP Lab 02 starter**

1. Put your own color JPG/PNG image (at least 300 x 300) in this folder.
2. Activate your project virtual environment and install dependencies:
   python -m pip install -r requirements.txt
3. Run: python lab02.py your_photo.jpg
4. The program saves resized_crop.png, grayscale_histogram.png,
   color_channels.png, crop_resize_comparison.png, bit_depth_comparison.png.
5. For your submission, include your input image, lab02.py, .gitignore,
   resized_crop.png, grayscale_histogram.png, and your lab report.
6. The lab report must include labeled evidence, code below each result,
   student details, and your own written interpretations.
